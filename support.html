Support

Get unstuck without leaking secrets.

For setup questions, connection issues, or bug reports, email support or open a GitHub issue. Keep passwords, private keys, hostnames, IP addresses, tokens, and production command output out of public reports.

Before reporting

Connection checks

  • Confirm host, port, username, and authentication outside SwiftTerm.
  • For key auth, verify that the server accepts the assigned public key.
  • The current live SSH path supports password and Ed25519 private-key authentication.
Files

SFTP and sync

  • SFTP supports list, upload, download, delete, rename, and create-directory operations.
  • Local document bookmarks can be reused or removed from the Files screen.
  • The iOS-safe sync runner uses SFTP-backed upload and download execution.
Billing

Subscriptions

SwiftTerm uses Apple In-App Purchase for subscription flows. If purchase or restore fails, include the plan, device model, iOS version, and approximate time of the attempt.

Contact path

Public support

Email support@swiftterm.app for App Store support and general questions. Use privacy@swiftterm.app for privacy-specific questions.

SwiftTerm support is privacy-safe by default.
