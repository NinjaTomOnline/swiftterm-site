Pitch

SwiftTerm is a mobile incident console.

It gives operators a focused way to inspect hosts, run SSH sessions, move files over SFTP, use snippets, and run local network checks from iPhone and iPad.

Platform

iPhone and iPad

Native SwiftUI interface targeting iOS and iPadOS with portrait and landscape support, hardware-keyboard workflows, and iPad workspace layouts.

Trust

Local-first by design

Private keys live in Keychain, analytics are opt-in and sanitized, diagnostics are redacted before sharing, and the current build has no server-side credential store.
