Privacy policy

Terminal data stays local by default.

Last updated May 1, 2026. This policy describes the current SwiftTerm build and should be reviewed again before App Store submission if analytics, sync, support, or crash-reporting providers change.

Email privacy Email support

On device

SwiftTerm stores host profiles, public keys, snippets, settings, transfer state, and subscription UI state in the app container. Private SSH key material is stored in Keychain.

Connections

When you connect to a server, SwiftTerm sends the host, port, username, and selected authentication material only to the server you choose. SwiftTerm does not run a server-side credential store for the current build.

Purchases

Subscriptions are processed by Apple In-App Purchase. SwiftTerm uses purchase and entitlement status to unlock premium features. Payment information is handled by Apple, not by SwiftTerm.

Analytics

The app includes a privacy-first analytics layer that must be opted into before use. It rejects hostnames, commands, key material, emails, IP addresses, and other sensitive values. No advertising identifier or cross-app tracking is used.

Future sync

CloudKit sync, team collaboration, marketplace distribution, and production AI execution are planned features. They are not active data-transfer features in the current build and will need updated privacy review before launch.

Support reports

If you contact support, include only the details needed to diagnose the issue. Email privacy questions to privacy@swiftterm.app. Do not send passwords, private keys, hostnames, IP addresses, access tokens, or production command output through public issue reports.

SwiftTerm keeps terminal work local-first.
