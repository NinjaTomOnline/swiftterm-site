# SwiftTerm One-Sheet

## Positioning

SwiftTerm is the mobile incident console for iPhone and iPad operators who need SSH sessions, SFTP transfers, snippets, and local network checks when the laptop is out of reach.

## What It Does

- Opens native terminal sessions for saved SSH hosts.
- Supports password and Ed25519 private-key authentication in the current live SSH path.
- Stores private key material in Keychain.
- Reviews known-host fingerprints before trust.
- Browses, uploads, downloads, renames, deletes, and creates directories over SFTP.
- Runs sandboxed local-shell commands for DNS, WHOIS/RDAP, TCP reachability, TLS checks, subnet math, and guarded SSH/Telnet launch helpers.
- Keeps analytics opt-in and diagnostics redacted before sharing.

## Product Boundaries

SwiftTerm does not currently ship Mosh bindings, live RSA SSH private-key authentication, production CloudKit sync launch, collaboration backends, marketplace distribution, true delta rsync, guaranteed long-running background transfer execution, or production AI execution.

## Audience

SwiftTerm is built for developers, sysadmins, network operators, web-hosting maintainers, and technical teams who need a privacy-first remote-access workspace on iPhone and iPad.
